# Expense-Tracker-with-app

Project: Expense Tracker Web App

📌 Project Overview

Problem: Students and working professionals struggle to track daily expenses.

Solution: A web app where users can:

Add income/expense

View balance

Delete transactions

Data saved in browser (LocalStorage)

Tech Stack:
HTML + CSS + JavaScript (Beginner to Intermediate Level)
